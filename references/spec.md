### 3. 一、分段精读

每个区块固定 4 段：

```
[00:00]                     ← 时间戳，加粗，首行缩进归零
I didn't think this ...     ← 英文段，首行缩进 2 字符
我从没想过，……              ← 中文段，首行缩进 2 字符
                            ← 空段（做区块隔离）
```

- 时间戳只保留**每段起始**，格式 `[MM:SS]`
- 每段 **90–130 词**
- **短素材允许 80–90 词/段**：素材总量小（如 10 分钟以内、不足 1500 词）或语义天然碎时，**宁可段落略短，也不要把两个不相关的意思硬拼成一段**。下限仍不低于 80 词——低于 80 说明该并入相邻段
- 区块之间用**真空段**隔离，**不是**靠段间距

### 4. 二、重点词汇（**2026-09-24 提速改版**：全文唯一的"知识清单"节）

- 按主题分组，**固定 3 组**，如：① 关系与择偶 ② 情绪与心态 ③ 句式与搭配
- 每组 **7–8 条**，**全文 20–22 条**（原 30–40 条，砍掉"认识但不必查"的水词）
- 组标题单独一段，**必须写成三级标题**：

```

```

  ⚠️ **`###` 不能省**。markdown 的 `###` 才会落成 **16pt 加粗 + 首行缩进归零**；
  只写 `① 关系与择偶` 会被当成**正文段**，拿到 12pt、不加粗、首行缩进 2 字符。
  - **自查判据**：`set_indent.py` 段落分类里的 **HEAD 数**。
    3 组词表 + 大标题 + 一、 + 二、 → **HEAD 应为 6**；若只有 3，就是组标题掉进了 P 类。
  - 另一判据：`verify_docx.py` 的 `sz 取值` 应包含 `'32'`（16pt）。
- **每条固定 2 行**：

```
**1. soulmate**　n.　灵魂伴侣
例：I don't believe there's such thing as soulmate. — 我不相信有"灵魂伴侣"这回事。
```

- **只有"有坑"的词条**才加第 3 行 `提示：`，**全文 6–8 条**，不是每条都写：

```

```

- ❌ **废话提示一律不写** —— "搭配介词 with""比 xx 正式"这种属于常识，占了行数没价值。
- ✅ **「提示」可以兼写句式看点**（原来是「重点句子」那一节的活）。
- ✅ **允许收"句式 / 搭配型词条"**，例如 `instead of doing A, do B`、`start to wonder if…`、

  等于把原「重点句子」里最值钱的语法点保住了，**且不新增任何章节**。

## 三、字体字号

| 对象 | 英文（ascii/hAnsi） | 中文（eastAsia） | 字号 |
|---|---|---|---|
| 正文（英文段 / 中文段 / 词汇 / 句子 / 时间戳 / 空段） | `Calibri` | `仿宋` | `12pt`（小四） |
| 文档大标题 | `黑体` | `黑体` | `22pt`，加粗，居中 |
| 各级小标题（一、/ 二、/ ①…） | 继承 Calibri | 继承 仿宋 | `16pt`，加粗 |

落盘写法：
- 基准写进 `styles.xml` 的 `docDefaults/rPrDefault` **和** `Normal` 样式：
  `<w:rFonts w:ascii="Calibri" w:hAnsi="Calibri" w:eastAsia="仿宋" w:cs="Calibri"/>` + `<w:sz w:val="24"/><w:szCs w:val="24"/>`
  （`24` 是半磅值，`24/2 = 12pt`）
- 大标题：`<w:rFonts ... 黑体 .../>` + `<w:sz w:val="44"/>`（22pt）+ `<w:jc w:val="center"/>`
- 小标题：`<w:sz w:val="32"/>`（16pt）

## 四、段落格式

| 项 | 值 | 落盘写法 |
|---|---|---|
| 行距 | 1.4 | `<w:spacing w:line="336" w:lineRule="auto"/>`（336/240 = 1.4） |
| 段前间距 | 0 | `w:before="0"` |
| 段后间距 | 6pt | `w:after="120"`（120 twips = 6pt） |
| 正文首行缩进 | 2 字符 | `<w:ind w:firstLineChars="200"/>` |
| 标题 / 时间戳 / 头部行 / 空段首行缩进 | 0 | `<w:ind w:firstLine="0" w:firstLineChars="0"/>` |

**为什么用 `firstLineChars` 而不是 `firstLine`（磅值）**：字符数缩进会随字号自动换算，
字号改了不用重算。用户手工改的也是 `firstLineChars="200"`。

**首行缩进必须逐段显式设**，不能只靠 `docDefaults` / `Normal` —— **WPS 不认文档默认样式里的 `<w:ind>`**。

## 六、标点与引号（2026-09-24 定）

- 中文里的**双引号一律用 ASCII 直引号 `"`**（U+0022），**不要用中文弯引号 `“ ”`**（U+201C/U+201D）。
  - 用户原话：「中文引号要从弯引号 `“ ”` 统一成直引号」。
  - ⚠️ **第一份成品 `2026-09-23` 里恰好没出现过中文引号**（它只有 301 个英文撇号 `'`），
    所以别拿它当"弯 / 直"的对照物 —— 判据就是**用直引号**。
  - 第二份 `2026-09-24` 误用了 86 对弯引号，已统一为直引号。
- 中文里的单引号同理用 ASCII `'`，不用 `‘ ’`。
- 其余中文标点（，。！？：；、——…（）《》）照常用**全角**。
- ⚠️ **写 markdown 中间稿时就用直引号**，不要等生成后再替换 ——
  中间稿里换容易漏；导入后引号散在几十个段落里，逐处改很麻烦。
